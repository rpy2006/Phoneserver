Cookies policy

The honest version first: this site sets no cookies. What it does use is a small amount of local storage in your browser for two preferences — the same strictly-necessary category a cookie banner would cover, minus the cookies.

1. The short version

  • No HTTP cookies are set by any page served here — not by the guide, the documentation, or these legal pages.
  • No analytics, advertising or social embeds run on these pages — not even the optional ad-network tag, so there is nothing that would set a tracking cookie in the first place.
  • Two preference values are kept in your browser's local storage, on your device only: the documentation theme and your answer to this banner.
  • The local file server does not send Set-Cookie responses; session-free password headers are used instead.
  • The optional ad server on port 8090 also sets no cookies. Its dashboard stores a bearer token and theme in local storage; delivery uses a server-side visitor hash, not a browser cookie.

Why a banner at all? Local storage is treated like a strictly-necessary cookie by most privacy rules, but we would rather explain it than assume. The banner records only that you have seen and accepted this explanation.

3. The consent banner

Until you press Accept, a banner is shown at the bottom of each page. On acceptance, the timestamped value above is stored locally and the banner is dismissed on every page of this site. If your browser blocks local storage, the banner may reappear — it is the only consequence, and the pages remain fully usable either way.

4. No third-party cookies

These pages load no third-party scripts, fonts, frames, pixels or widgets — the animation libraries they do use (Three.js, Anime.js, Lenis) are served from this site itself. No third party can set or read anything through them. There are no cookie identifiers shared across sites and nothing to opt out of beyond the banner itself.

5. The local PhoneServer

The server you run on your phone is a different thing from this documentation site. It responds to HTTP requests without issuing cookies: authentication travels in the X-Auth-Password header (or HTTP Basic), and request metadata is kept only in memory for the live dashboard counters. Anyone else on your LAN still sees ordinary HTTP traffic — that network trust boundary is described in the privacy policy and security model.

5.1 Optional ad-network dashboard

The Ad Network Manager is served from the same phone but on a different port, and it is a separate origin in browser terms. It sets no HTTP cookies. After login it keeps the session bearer token in localStorage under adnet_token, and remembers the light/dark choice under adnet_theme. Logging out or clearing site data for that origin removes them. Ads served to other websites do not rely on cookies: the SDK sends a signed event token, and the server derives a daily, non-reversible visitor hash from the request IP and user agent. No raw IP address is written to the event log.

6. Managing and withdrawing consent

  • Withdraw: clear site data / local storage for this site in your browser settings — the banner will ask again on your next visit.
  • Block storage: most browsers let you block local storage per site; the pages still work, preferences just do not persist.
  • Inspect: the values above are visible in your browser's developer tools under Application → Local Storage.
  • App data: clearing or uninstalling the Android app removes everything the app stores on the device.
  • Ad dashboard: use Log out, or clear site data for http://<phone-ip>:8090, to remove adnet_token and adnet_theme.

7. Changes and contact

If this site ever gains a capability that does require cookies — an embedded service, a hosted form, analytics — this page and the banner will be updated before it is enabled, with a new version number and effective date. Until then, the "cookies set: none" figure at the top stays true.

Questions go through the repository issue tracker or the distribution channel you received PhoneServer from. See also the privacy policy, Terms of Service and legal notice.
