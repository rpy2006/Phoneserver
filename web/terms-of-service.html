2. What PhoneServer is

PhoneServer turns an Android device into a local HTTP server (fixed port 8080) that serves files, a small website, custom JSON endpoints and a local SQL/file data platform to other devices on the same trusted network. It is a self-hosting tool: you are the operator, the administrator and the data controller.

It is not a cloud service. There is no account, no uptime commitment, no support desk and no data processing on our side — we never receive your content or your credentials. Everything runs on your device under your control.

5. Your network, your responsibility

PhoneServer is built for a trusted LAN. You are responsible for the network you run it on, for who is allowed onto that network, and for anything you share through the server — including files you would not want an unauthenticated guest to download.

  • The server speaks plain HTTP without TLS. Traffic can be read by anyone able to observe the local network.
  • The optional password is a shared credential, not per-user identity; anyone who has it gets the access it gates.
  • Exposing port 8080 to the public internet — by port-forwarding, DMZ or tunnel — is outside the supported configuration and is done entirely at your own risk.

The recommended setup lives in the hardening checklist of the production guide; the analysis of controls and gaps is in the security model.
