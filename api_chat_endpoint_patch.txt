Add /api/chat to SimpleHttpServer.java
========================================

1. In route(), find the else-if chain that dispatches "/api/browse", "/api/mkdir",
   etc. Add a new branch BEFORE the fallback "startsWith(/api/)" custom-endpoint
   check (chat should take priority over user-defined static endpoints at the
   same path):

       } else if (path.equals("/api/chat") && req.method.equals("POST")) {
           serveChat(out, req.body);
       } else if (path.startsWith("/api/")) {
           serveCustomApi(out, req.path, req.method);
       }

2. Add this handler method near your other handlers (e.g. next to serveStats):

    private void serveChat(OutputStream out, byte[] body) throws IOException {
        if (!LlmEngine.get().isModelLoaded()) {
            writeResponse(out, 503, "application/json",
                    "{\"error\":\"model not loaded\"}".getBytes(StandardCharsets.UTF_8));
            return;
        }
        try {
            JSONObject requestJson = new JSONObject(new String(body, StandardCharsets.UTF_8));
            String prompt = requestJson.optString("prompt", "");
            if (prompt.isEmpty()) {
                writeResponse(out, 400, "application/json",
                        "{\"error\":\"missing 'prompt'\"}".getBytes(StandardCharsets.UTF_8));
                return;
            }

            String response = LlmEngine.get().generateBlocking(prompt);

            JSONObject result = new JSONObject();
            result.put("response", response);
            writeResponse(out, 200, "application/json",
                    result.toString().getBytes(StandardCharsets.UTF_8));
        } catch (Exception e) {
            writeResponse(out, 500, "application/json",
                    ("{\"error\":\"" + e.getMessage() + "\"}").getBytes(StandardCharsets.UTF_8));
        }
    }

3. Should /api/chat require the device password, like /files and /api/browse do?
   Given this runs actual inference (CPU + battery cost per call), I'd recommend
   yes - add "/api/chat" to the same protected-paths check that already gates
   /api/browse, /files/*, etc., so a stranger on your Wi-Fi can't spam your phone
   with generation requests. That's a one-line addition to the existing
   isAuthorized() check block, same pattern as everything else in that list.

Note: this endpoint blocks the request thread for as long as generation takes
(likely a few seconds for a 135M model on a phone CPU). That's fine for the
one-thread-per-connection model this server already uses, just don't expect
sub-second responses.
